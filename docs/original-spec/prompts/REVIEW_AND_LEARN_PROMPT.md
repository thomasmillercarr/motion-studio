# Review and learn prompt

Review the current video/project using the supplied preview, contact sheets and feedback notes.

1. Inspect each note in context.
2. Identify the affected scene and element.
3. Classify each note as project-specific, user preference, reusable design principle, repeated agent failure, engine defect or performance issue.
4. Propose the smallest targeted correction.
5. Do not rewrite unrelated scenes.
6. Check whether the same defect has occurred before.
7. If a reusable system improvement is justified, draft a proposal in `learning/proposals/`.
8. Do not alter global skills or creative rules until the user approves.
9. Add a regression example for recurring technical/visual failures.
10. Update the project state and review changelog.
