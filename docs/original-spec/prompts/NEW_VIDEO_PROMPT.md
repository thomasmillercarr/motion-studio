# New video project prompt

Create a new video project using the Claude Motion Studio workflow.

Inputs:
- Brief or script: [provide path or paste]
- Voiceover: [optional path]
- Desired runtime: [if known]
- Platform/aspect ratio: [if known]
- Audience: [if known]
- User references: [optional URLs/files]
- Avoid: [optional constraints]

Start with creative intake, not animation code.

1. Read the brief and identify the communication goal.
2. Ask no more than 3–5 high-impact questions if required.
3. Search the local reference vault.
4. Research independently using available sources and tools.
5. Produce a compact evidence pack.
6. Develop three distinct visual directions.
7. Recommend one direction with clear reasoning and performance implications.
8. Wait for approval.
9. Produce storyboard and proof-of-style only after approval.

Do not use any technique merely because it is easy to implement. Explain the narrative reason and reference principle behind each major visual choice.
