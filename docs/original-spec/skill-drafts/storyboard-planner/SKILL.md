# Storyboard Planner

For each scene specify:
- Narration/message and time range.
- Viewer takeaway.
- Visual purpose.
- Composition and focal point.
- Elements entering, changing and leaving.
- Motion behaviour, timing and easing.
- Transition to the next scene.
- Reference IDs and adapted principles.
- Rendering approach and performance tier.

Prefer visual variety with a coherent design system. Do not create one scene per sentence automatically. Combine beats where the visual idea benefits from continuity.

Output `storyboard.md` and `storyboard.json`.
