# Reference Researcher

Find high-quality references by visual behaviour and narrative purpose, not merely by subject.

## Workflow

1. Search the local vault first.
2. Search curated source directories and available external research tools.
3. Prefer original creator/studio pages and credited work.
4. Record URL, creator, title, access status and provenance.
5. Analyse composition, type, palette, material, movement, camera and transitions only when observable.
6. Separate observed facts from interpretation.
7. Extract adaptable principles and explicitly state what not to copy.
8. Score craft, relevance, specificity, explainability, provenance and reproducibility.
9. Return 5–10 concise reference cards maximum.

Do not bypass access controls, scrape restricted pages or redistribute protected media.
